# Голосовой протокол УЗИ — прототип

Диктовка размеров и описаний во время исследования → поля шаблона → нормы и расчёты → готовый протокол.

Открыть: https://jumagulovnm2016-ai.github.io/uzi-voice/ (Google Chrome на компьютере или Android).

- Шаблоны: щитовидная железа, органы брюшной полости.
- Распознавание речи — встроенное в Chrome (через серверы Google, нужен интернет). Не диктуйте ФИО и данные пациентов.
- Нормы ориентировочные, для прототипа — сверяйте со своими стандартами.
